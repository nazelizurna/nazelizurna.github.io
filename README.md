# Nazeli Zurna — GitHub Pages

A responsive personal portfolio inspired by the supplied dark, dotted-grid reference. Built with plain HTML, CSS, and JavaScript.

## Publish on GitHub Pages

1. Create a GitHub repository named **`YOUR-USERNAME.github.io`** (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment. Your site will be available at `https://YOUR-USERNAME.github.io/`.

## Personalize before publishing

Search the HTML for these placeholders and update them:
- `https://github.com/` — replace with your GitHub profile and project repositories.
- `https://www.linkedin.com/`, `https://www.behance.net/`, `https://www.instagram.com/` — replace with your profile URLs or remove any networks you don't use.
- `hello@example.com` — replace with your public contact email.
- Sample project titles and descriptions — replace with your actual projects.

The page uses Google Fonts (Inter and DM Mono); if fonts are unavailable, it falls back to system fonts. The theme toggle works locally and requires no dependencies.
